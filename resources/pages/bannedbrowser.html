BannedBrowser_

Version {{VERSION}} — a web browser written from scratch in Rust.

Every web-platform component — URL parsing, HTTP, HTML, DOM, CSS, style, layout, painting and this very page — is BannedBrowser's own code. Only platform glue (windows, fonts, image codecs, TLS) comes from third-party crates.

Credits

Built on the WHATWG and CSSWG specifications, tested with html5lib-tests and Web Platform Tests.

The name is a nod to Silver Wolf's nickname, "Banned". BannedBrowser is an unofficial fan-named project, not affiliated with, endorsed by, or sponsored by HoYoverse. UI inspired by Firefox; not affiliated with Mozilla.
